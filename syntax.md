### Tokens
1. **Set**:

**Без явного типа (автоматическое определение типа):**
```nnv
set value = 5;
```

**С явным типом:**
```nnv
set value: i64 = 5;
set counter: u8 = 10;
set flag: int = 42;
```

**Поддерживаемые типы:**
- `i64` - 64-битное целое число со знаком (генерируется как `long` в C)
- `u8` - 8-битное целое число без знака (генерируется как `unsigned char` в C)
- `int` - целое число (генерируется как `int` в C, используется по умолчанию при автоматическом определении)
- `char` - символ (генерируется как `char` в C)

2. **Exit**:
```nnv
exit(136);
```
Ничего интересного, просто выходит из программы с кодом возврата. Принимает `i8` как код возврата.

3. **Putchar**

**Вывод числа как символа**:
```nnv
putchar(90); // Превратит 90 в символ по таблице ASCII
```

**Вывод символа через одинарные кавычки**:
```nnv
putchar('A'); // Выводит символ 'A'
```

**Вывод управляющего символа**
```nnv
putchar('\n'); // Переведет на новую строку
```
**Управляющие символы:**
- `'\n'` - Новая строка
- `'\r'` - Возврат каретки
- `'\b'` - Возврат на предыдущую позицию
- `'\t'` - Табуляция
- `'\0'` - Нуль-терминатор
